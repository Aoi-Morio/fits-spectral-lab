# FITS Spectral Lab

FITS・CSVのスペクトルを読み込み、ブラウザー画面で天文分光の解析を行うローカルアプリです。日本語UI、合成デモ、科学計算のテストを備えています。

## できること

- 1次元FITSスペクトル、2次元FITS画像、FITSテーブル、CSV/TXT/TSVの読み込み
- HDU・テーブル列の選択、FITSヘッダーの表示
- Astropy WCSによる波長軸の解釈、単位のÅへの統一、SDSSのloglam/COEFF0/COEFF1への対応
- 2次元画像の空間範囲を加算し、別の背景範囲の行中央値を差し引く抽出
- 波長情報がないデータのピクセル表示と手動の線形波長校正
- 拡大可能なスペクトル、表示専用のガウス平滑化、線の候補検出
- 連続光推定、単一の輝線／吸収線のガウスフィット
- 中心、FWHM、ガウス積分強度、範囲内の積分強度、等価幅、赤方偏移の表示
- 元サンプルと連続光のCSV/FITS保存、解析設定と測定値のJSON保存

## 起動

Python 3.11以上が必要です。WindowsのPowerShellで:

```powershell
git clone https://github.com/Aoi-Morio/fits-spectral-lab.git
cd fits-spectral-lab
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m streamlit run app.py
```

セットアップ後は `Start-SpectralLab.bat` をダブルクリックしても起動できます。ブラウザーで <http://127.0.0.1:8501> を開いてください。

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m streamlit run app.py
```

サーバーは初期設定で127.0.0.1だけに接続します。ファイルはローカルのStreamlitサーバーで解析され、外部サービスへ送信する機能はありません。利用統計の送信も無効です。観測ファイルは `.gitignore` でGitの管理対象から除外しています。

## はじめて使う

1. 起動直後の合成デモでスペクトルを確認します。Hα付近に3本のガウス輝線とノイズを入れています。
2. 「線の解析」で範囲を6554〜6572 Å付近に指定すると、Hαの中心約6562.8 Å、FWHM約4.00 Å、積分強度約102.27（任意フラックス単位 × Å）が得られます。ノイズにより値は少し変わります。
3. 観測ファイルをサイドバーから開きます。FITSではデータのあるHDUを選び、2次元画像なら分散方向と加算範囲を指定します。
4. 連続光の次数、線の範囲、輝線／吸収線を指定します。範囲には線の裾も含めてください。
5. 「保存・ファイル情報」でスペクトルと測定結果を保存します。「練習用デモ FITS」を実際に読み込むこともできます。

## 入力形式

**FITS画像**: 1次元または2次元。2次元はFITS axis 1または2の分散方向を選び、空間方向の範囲 `[開始, 終了)` を加算します。範囲は0始まり、終了を含みません。背景は抽出範囲と重ならない範囲を指定します。空間軸と結合した分光WCSはエラーとして扱います。

**FITSテーブル**: `WAVELENGTH` / `WAVE` / `LAMBDA` / `LOGLAM` と `FLUX` / `FLAM` / `INTENSITY` を自動候補にします。任意の列もUIで選択できます。1行に配列が入った形式か、1点ずつのスカラー行に対応します。誤差は1σ標準偏差、`IVAR` は逆分散として読みます。波長列の単位がない場合はUIで指定してください。`LOGLAM` はlog10(波長/Å)です。

**CSV/TXT/TSV**: 波長、フラックス、任意の1σ誤差の順で2〜3列。UTF-8、カンマ・タブ・空白・セミコロン区切り、任意のヘッダー1行、`#`で始まるコメント行に対応します。列の並べ替えは行いません。第1列の単位はUIで選びます。

```csv
wavelength,flux,error
6560.0,10.3,0.35
6560.1,10.7,0.35
```

解析には最低8点必要です。非有限の軸／フラックス、非有限または0以下の誤差は除外します。軸は昇順に並べ、重複はエラーにします。

## 解析の定義と限界

連続光は線の解析範囲を除外した全体データの多項式（0〜5次）です。最大8回の3σクリッピングを行い、スケールはMADから推定します。誤差があれば標準偏差の逆数で重み付けします。

線は連続光を差し引いた元データに `A exp(-(λ−μ)²/(2σ²)) + c` をフィットします。ガウス積分強度は全範囲へのモデル積分 `Aσ√(2π)`、FWHMは `2√(2 ln 2)σ` です。別に、指定範囲の連続光差分を台形積分した強度も記録します。平滑化は解析に使いません。

等価幅は指定範囲の `∫(1−F/C)dλ` です。吸収で正、輝線で負になります。連続光が0以下を含む範囲では計算しません。正規化されていない生データでも、連続光が妥当な場合に計算できます。

入力誤差がある場合は絶対誤差の重み付き最小二乗、ない場合はフィット残差からの誤差推定です。積分強度の誤差は振幅と幅の共分散を含めます。連続光推定の誤差、抽出・背景推定誤差、画素間相関、装置の分解能は誤差値に含みません。

この初期版は、バイアス／ダーク／フラット補正、宇宙線除去、最適抽出、感度校正、装置線幅の補正、重心運動補正、線の自動同定、キューブ、複数スペクトルの同時表示、重なった線の同時フィットには対応していません。空気中波長と真空波長は変換しません。赤方偏移は同じ波長系の静止波長を使ってください。

FITS保存では抽出後の1次元テーブルを新規作成します。元ファイルのHDU構造と装置固有メタデータは保持しないため、元ファイルも保存してください。

## テスト

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
```

既知の輝線・吸収線の中心／幅／積分、極小フラックスでの安定性、FITS WCSのピクセル原点と単位、非線形WCS、2次元抽出と背景差分、SDSS逆分散、保存ファイルの再読み込み、画面の起動とエラー表示を検証します。GitHub ActionsにもWindows/Linuxのテストを設定しています。

FITSとWCSの実装は [Astropy FITS](https://docs.astropy.org/en/stable/io/fits/index.html) と [Astropy WCS](https://docs.astropy.org/en/stable/wcs/index.html)、フィットは [SciPy curve_fit](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.html) を使用しています。
